# Учёт производства

Сервис учёта выхода сотрудников и выпуска продукции бригадами с передачей данных в 1С.

Концепт: отметки прихода и ухода приходят с терминала распознавания лиц, бригадир вводит выпуск за смену,
кладовщик подтверждает его в 1С, после чего изделия встают на склад, а бригаде начисляется сдельная оплата.

## Что уже есть

Приём отметок с терминалов ZKTeco по протоколу ADMS (PUSH): терминал сам присылает каждую отметку на сервер.

| Адрес | Кто вызывает | Зачем |
| --- | --- | --- |
| `GET /iclock/cdata` | терминал | получить настройки обмена при включении |
| `POST /iclock/cdata?table=ATTLOG` | терминал | прислать отметки |
| `GET /iclock/getrequest` | терминал | забрать команды (добавить или удалить сотрудника) |
| `POST /iclock/devicecmd` | терминал | сообщить результат команды |
| `GET /api/punches?day=2026-10-08` | бригадир, 1С | отметки за день |
| `POST /api/devices/{SN}/users` | администратор | добавить сотрудника на терминал |
| `DELETE /api/devices/{SN}/users/{PIN}` | администратор | убрать сотрудника с терминала |
| `GET /api/commands/{id}` | администратор | выполнил ли терминал команду |

Запросы к `/api` требуют заголовок `Authorization: Bearer <API_TOKEN>`.

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
API_TOKEN=придумайте-длинный-токен ALLOWED_SERIALS=серийный_номер_терминала \
  .venv/bin/uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8080
```

Переменные окружения:

- `API_TOKEN` — токен для `/api`; без него `/api` закрыт.
- `ALLOWED_SERIALS` — серийные номера терминалов через запятую. Пусто — принимать от всех (только для отладки).
- `DB_PATH` — файл базы SQLite, по умолчанию `uchet.sqlite3`.
- `TIMEZONE_HOURS` — часовой пояс терминала, по умолчанию 3 (Москва).

## Настройка терминала

В меню терминала: «Связь» → «Облачный сервер» (ADMS). Адрес сервера — адрес этого сервиса, порт 8080
(или 443 за HTTPS-прокси), домен вместо IP, если терминал это позволяет.

## Проверка без терминала

```bash
.venv/bin/python -m pytest -q
.venv/bin/python tools/terminal_sim.py --server http://localhost:8080 --sn TEST0001 --pin 101
```

Симулятор повторяет обмен настоящего терминала: получает настройки, отправляет отметку, забирает команды.
